# Reference: Complete Option Lists

These are the **complete option listings** and **technical parameters** for every command.

Use these when you need to:
- Find all available options
- Understand format requirements
- Fine-tune behavior

## By tool

- **[spratlayout](spratlayout.md)** — All packing options
  - Algorithms, profiles, deduplication
  - Input formats, caching, multipacking

- **[spratpack](spratpack.md)** — All image generation options
  - Compression, GPU formats, variants
  - Dilation, scaling, protection

- **[spratconvert](spratconvert.md)** — All metadata options
  - Transform selection, output formats
  - Custom Jsonnet transforms
  - Complete data schema

- `man sprat-cli` — Full manual (after install)
